Road map

Planned improvements and features for Dispute Map

Features

2

{ Filtering by Union Planned

Currently not possible to filter entries by Union.

{ Show events where other people wanted (Solidarity Actions?) Planned

Showing events where a union is calling for other people to join them to show up and join them and that being front and centre is important for the website.

Bug Fixes

4

{ Fix filtering Bug

  • Category filter discards earlier entries. Currently events only show their most recent entry, and the category of previous entries is discarded. Fixing this, so for example when you filter to ballots, it shows all events with ballots, without removing them, is a plan.
  • Date range filtering has the same issue. Similar issue exists with date range filtering.
  • State filtering is unreliable. Filtering by state also has issues on occasion.

{ Improve UI Bug

  • AI sucks Currently UI is very basic and drawing from “vibe coded” style (ew). Improving this so it’s not the case would be good
  • Use proper SVG’s instead of Emojis for symbols
  • Fix Mobile Viewability Mobile Mode Currently has major issues with readability and text
  • Fix Filter Usability Filters are not very usable at the moment and would work better as a collapse menu

Performance

1

{ Improve dynamic serving Performance

Currently all information is served up from one big data.js file. This works alright for now but as the amount of entries increase, it would be better to improve this by only serving up data from past month by default, and then letting people filter stuff as appropriate.

Collaboration

2

{ Allow reporting of actions Collaboration

Currently there is a framework to report an event (Strike, lockout, dispute e.t.c.), but server is not setup to handle requests. Setting up a way to handle the ability for people to file forms and then accept or reject if a dispute is legitimate would be awesome.

{ Wiki integration Dream

This is more of a dream, but integrating with a media wiki instance which anyone can contribute to, and then tying links to each dispute and also pulling information into each other would be awesome.

Other

1

{ Drop AI from data ingestion Collaboration

Use collaboration features to stop using AI for data ingestion.
